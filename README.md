# Our Little World 💕

A private, disappearing-message chat app for two people.

## Features
- Text chat with Snapchat-style disappearing messages
- Photo and video sharing with download option
- Voice and video calls (WebRTC)
- Auto-logout when tab is hidden or window closed
- Romantic glassmorphism UI with floating hearts
